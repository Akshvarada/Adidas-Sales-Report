# Adidas-Sales-Report
This repository contains a Power BI dashboard analyzing Adidas' US sales data, highlighting key metrics like total units sold (625K) and total sales ($243M). It includes monthly sales trends, product type breakdowns, and geographical insights. Files include the Power BI report, dataset, and a screenshot of the dashboard for reference.


## Overview
This repository contains a comprehensive analysis of Adidas' US sales data, created using Power BI. The report highlights key performance metrics, sales trends, and geographical distribution of sales.

![Adidas Sales Report](M3%20A5%20Akshitha%20Varada.png)

## Files in This Repository
- `Adidas Sales report.pbix`: The Power BI report file.
- `Adidas US Sales Datasets.xlsx`: Dataset used for the analysis.
- `M3 A5 Akshitha Varada.png`: A screenshot of the report dashboard.

## Key Insights
1. **Total Units Sold**: 625K
2. **Total Sales**: $243M
3. **Sales Breakdown**:
   - **Product Types**: Street Footwear, Athletic Footwear, Apparel.
   - **Channels**: In-store, Online, Outlet.

4. **Monthly Trends**:
   - Peak sales in January (86K units).
   - Sales declined during September and November.

5. **Geographical Analysis**:
   - Sales concentrated across key cities in the United States.

## How to Use
1. **Power BI File**:
   - Open the `Adidas Sales report.pbix` file in Power BI Desktop.
   - Connect to the provided dataset (`Adidas US Sales Datasets.xlsx`).
   - Customize the report as needed.

2. **Datasets**:
   - `Adidas US Sales Datasets.xlsx` contains the raw data used for the report.

3. **Visualization**:
   - Refer to the screenshot for an overview of the dashboard layout.

## Prerequisites
- Power BI Desktop installed on your computer.
- Basic understanding of Power BI to interact with the report.
